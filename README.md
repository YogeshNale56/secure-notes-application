# Secure Notes Application

A web-based application to securely create, store, and manage personal notes. Developed to eliminate manual note management and provide encrypted login for enhanced data confidentiality.

---

## 📅 Project Duration
**February 2024 – April 2024**

---

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Hibernate
- **Frontend:** JSP, HTML, CSS, Bootstrap
- **Database:** MySQL
- **Architecture:** MVC (Model-View-Controller)
- **Security:** Encrypted login, input validation

---

## ✨ Key Features
- Secure login for users with encrypted credentials
- CRUD operations for creating, updating, deleting, and reading notes
- Admin dashboard to monitor user activity
- Input validation to ensure data accuracy
- User-friendly interface with JSP and Bootstrap
